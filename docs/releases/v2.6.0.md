# PPX v2.6.0

## 转换中心

- 新增统一的“转换中心”，覆盖通用格式转换、图片合成 PDF、PDF 合并和引擎能力检查。
- 图片、PDF、视频工具中的旧格式转换入口迁移到转换中心；历史任务与旧入口继续自动重定向。
- 混合文件会按共同目标格式收敛，目标格式按源扩展名记忆，批量部分失败时保留已经完成的输出。
- 转换任务接入持久任务中心，可查看状态、结果文件和失败原因。

## 内置 FlyingMouse Format

- 经授权将 FlyingMouse Format 0.6.5 CLI 固定为 `vendor/flyingmouse-format` 上游子模块。
- 构建时安装锁定的生产依赖，并把当前平台 Node.js 运行时、上游源码运行文件和许可证材料装入 PPX 安装包。
- 安装版不再要求用户单独安装 FlyingMouse Format 或在 PPX 同级放置源码。
- FFmpeg、LibreOffice、Poppler、Tesseract、qpdf 等大型可选引擎继续按本机环境动态启用。

## 界面与兼容性

- 转换中心复用 PPX 主题、密度、任务状态和响应式工作区，在窄窗口下自动切换为横向功能导航。
- 保留 FlyingMouse Format 作者牢蜂（LaoFeng）的署名、原始许可和生产依赖许可证摘要。
- 修正 README 中 PPX 许可证标识，使其与仓库中的 GNU AGPL v3 许可证一致。

## 开发者升级

首次检出请使用 `git clone --recurse-submodules`，已有工作区执行：

```bash
git submodule update --init --recursive
pnpm run init
```

也可以单独运行 `pnpm run prepare:flyingmouse` 重建当前平台的内置转换运行时。
