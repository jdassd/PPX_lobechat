# 🛠️ PPX - 多功能工具箱

一个现代化的跨平台桌面应用，集 PDF、Excel、系统工具和数字签章功能于一身。采用简洁美观的界面设计，一次付费，终身使用，无广告，持续更新。

**版本:** V1.0.0 | **作者:** Jdassd | **许可:** MIT

---

## ✨ 核心功能

### 📄 PDF 工具
- 🔗 **合并 PDF** - 快速合并多个 PDF 文件
- ✂️ **分割 PDF** - 灵活提取特定页面
- 📝 **提取文本** - 识别并提取 PDF 中的文本内容
- 🎨 **添加水印** - 为 PDF 添加文字或图片水印
- 🏷️ **数字签章** - 应用数字签名和电子印章

### 📊 Excel 工具
- 📥 **读写表格** - 支持 XLSX 格式的读取和编辑
- 🎯 **格式化** - 智能应用表格格式化和样式
- 💾 **数据交换** - 无缝导入导出数据

### 🖥️ 系统工具
- 📁 **文件对话框** - 原生系统文件/文件夹选择器
- ⚙️ **进程管理** - 实时监控和管理系统进程
- 📊 **系统信息** - 查看 CPU、内存、磁盘使用情况
- 🔧 **系统优化** - 一键清理和性能调优

### 🔐 数据存储
- 🔑 **加密存储** - 密钥-值加密存储，保护隐私数据
- 💾 **灵活后端** - 支持 JSON (轻量级) 和 SQLite (生产级) 两种数据库
- 🔄 **自动备份** - 数据自动备份和版本控制

### 🔄 自动更新
- 📦 **GitHub Releases** - 自动检查和推送最新版本
- ⚡ **无缝升级** - 后台下载，一键安装新版本
- 📢 **版本通知** - 新版本发布时自动提醒

## 📦 技术栈概览

### 前端技术
- **Vue 3** - 现代化的渐进式框架
- **Element Plus** - 企业级 UI 组件库
- **Vite** - 极速构建工具
- **Sass** - 强大的样式预处理器

### 后端技术
- **Python 3.8-3.11** - 稳定的运行时
- **Pywebview** - 跨平台桌面应用框架
- **PyInstaller** - 应用打包工具
- **PyPDF2** - PDF 处理库
- **openpyxl** - Excel 操作库
- **psutil** - 系统监控库
- **TinyDB/SQLAlchemy** - 灵活的数据存储

### 构建部署
- **pnpm** - 高效的包管理器
- **Node.js** - JavaScript 运行环境
- **Inno Setup** - Windows 安装程序生成
- **dmgbuild** - macOS DMG 制作
- **dpkg** - Linux DEB 打包
- **GitHub Actions** - 自动化 CI/CD

## 🏁 快速开始

### 安装应用
1. 前往 [GitHub Releases](https://github.com/jdassd/PPX_lobechat/releases) 下载对应平台的安装包
2. Windows: 运行 `.exe` 安装程序
3. macOS: 打开 `.dmg` 文件，拖拽应用到 Applications
4. Linux: 使用包管理器安装 `.deb` 文件

### 首次使用
1. 启动应用
2. 根据需要选择要使用的工具
3. 按照工具内的提示完成操作
4. 支持拖拽上传文件进行处理
