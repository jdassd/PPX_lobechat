# PPX v2.17.1 — 修复跨平台导航巡检与自动发布

v2.17.0 的 Windows、Linux 自动构建成功，macOS 在导航巡检中失败，因此没有创建正式 Release。本版修正该等待条件，承接 [v2.17.0 的功能与界面修正](https://github.com/jdassd/PPX_lobechat/blob/v2.17.1/docs/releases/v2.17.0.md)，保留原失败 Tag。

## 修复

- 工具视图使用异步加载，并在旧视图退出后挂载新视图。巡检原先固定等待 450 毫秒，可能在 macOS 上读到尚未挂载的空页面。
- 改为在 15 秒内轮询目标组件的标识、可见性和非空内容；不会把旧页面内容当成新页面加载完成。
- 每次巡检刻意将图片工具的脚本响应延迟 1200 毫秒，确保覆盖超过旧等待时长的真实加载场景；保留所有模块、文本交互与页面错误检查。

## 验证与发布

本地验证与失败日志定位见 [verification.json](https://github.com/jdassd/PPX_lobechat/blob/v2.17.1/docs/releases/assets/v2.17.1/verification.json)。三平台 CI 继续执行完整 Python 回归、前端检查、端到端流程和原生打包，全部成功后才生成正式 Release。

v2.17.0 的失败流程为 [38866132613](https://github.com/jdassd/PPX_lobechat/actions/runs/38866132613)，失败断言位于导航至“图片处理”之后；该证据指向测试等待不足，不将其描述为已确证的应用处理故障。

本版继续包含小图水印定位、首页收藏键盘行为、文本窄窗布局与主题结果区的修正，以及真实 PDF、Word、图片、转换中心和可选 FFmpeg 的回归。OCR、LibreOffice、原生安装、升级与恢复等未完成验收仍按 [验收记录](https://github.com/jdassd/PPX_lobechat/blob/v2.17.1/docs/refactor-acceptance.json) 保持 pending。
