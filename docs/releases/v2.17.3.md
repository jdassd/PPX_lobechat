# PPX v2.17.3 — 加密 PDF 与 Windows 窗口修复

修复 AES 加密 PDF 页码切割失败、Windows 默认窗口尺寸和边缘缩放问题，补齐旧窗口记录迁移及实际冻结程序回归。

## 修复

- 补齐 PyCryptodome AES 冻结依赖，统一 PDF 切割、拆分、合并的密码处理；支持空用户密码、逐文件合并密码，错误密码不产生输出。普通 PDF 不再因误填密码失败。
- Windows 按 DPI 和工作区规划首次窗口大小，隐藏启动期间设置原生尺寸，页面加载且尺寸准备好后显示。旧 schema1/2/3 窗口记录迁移后保持显示尺寸，新 schema4 保存实际逻辑坐标，连续重开不再缩水。
- Windows 边缘缩放交由原生窗口处理，移除拖动中逐次调用 JavaScript 调整尺寸的路径；最小尺寸按物理像素正确换算，最大化保留任务栏工作区。
- 首页按内容宽度重排标题、搜索和动作卡片，避免孤字换行及过度截断；快捷键提示在 Windows/Linux 显示 Ctrl，在 macOS 显示 ⌘。窄窗 PDF 页码输入不再裁切。
- 文件分类预览不再创建目标目录；复制分类撤销正确保留源文件并统计撤销项。工作流不持久化 PDF 密码。

## 验证

本机已通过 180 项 Python 测试、25 项前端规则、静态检查（0 错误，141 条既有警告）及生产构建。Windows 200% DPI 覆盖默认配置及三种旧记录各三轮启动恢复、16 项原生窗口检查、真实边缘拖动和关闭重开；加密 PDF 界面流程会重新打开输出核对页序与文本。冻结程序验证包含图片透明度、AES-256 PDF 切割及基础 OCR。

最终工作树的完整端到端、首页布局与冻结包结果记录在 [验证清单](assets/v2.17.3/verification.json)；正式产物由同一 Tag 的 Windows、macOS、Linux CI 检查并构建。v2.17.2 在发现旧窗口迁移缺陷后取消发布，保留标签且没有 Release。

窗口实测覆盖当前 Windows 200% DPI，未采集连续视频；其他 DPI、多屏、原生安装升级恢复、CEF、广泛 OCR 与 LibreOffice 场景仍待验收。
