# PPX v2.7.0

## 工作台重新设计

- 重新设计首页、功能导航和主要工具面板，统一视觉层级、间距与蓝色强调体系。
- 首页加入随时间变化的问候语和更明确的搜索入口，收藏、常用动作与最近任务继续集中展示。
- 工具名称和说明更贴近日常使用场景，减少内部术语，让图片、PDF、Excel、维护与印章功能更容易理解。

## 交互与可访问性

- 新增页面切换、命令面板和卡片进入动效，让不同工作区之间的切换更连贯。
- 统一键盘聚焦状态，提升键盘操作时的可见性。
- 尊重系统“减弱动态效果”设置，启用后会自动缩短动画与过渡。

## 保持本地优先

- 本次更新不改变文件处理边界：图片、文档、表格和任务记录仍默认保留在本机。
- 现有转换中心、任务队列、模块开关和工具入口继续兼容原有使用方式。
