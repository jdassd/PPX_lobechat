# PPX v2.17.5 — 浏览器采集安装与点选修复

修复浏览器采集的首次安装、点选回调和匹配数量显示，保留可重试的错误提示。

## 内容

- 冻结应用通过随包 Node CLI 安装 Chromium，避免把应用本身当作 Python 模块启动器。
- 点选线程正确处理 Playwright 事件，实际容器数量与样本文本分别传递。
- 环境检测、启动和预览失败后保留错误并提供重试；Google 验证页提示人工验证，保持会话供恢复采集。
- 重复文件扫描回归为异步结果提供合理等待时间，保留扫描截断等全部结果断言。
