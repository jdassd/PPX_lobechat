# PPX v2.8.0

本次围绕处理结果正确性和完整操作流程重构，保留 Vue 3、Element Plus、Python 与 Pywebview 技术栈。

## 主要更新

- 桌面 API 改为独立服务委托，修复 Word/PDF 输出路径及印章方法冲突。
- 统一动作描述、SQLite 任务历史、逐文件结果与输出资产；新增部分成功、可取消工作进程和仅重试失败项。
- 切换工具保留草稿，支持非敏感配置恢复、预设、共享文件队列及结果交给下一工具。
- PDF 支持千页文件的分页缩略图、批选、排序和撤销；Word 改善表格行、分节和真实分页处理；Excel 保留数据类型并明确公式策略。
- 完善图片效果预览、视频编码检查与进度、OCR 方向和置信度、文件操作预演与撤销、印章预览导出一致性。
- 工作流支持动作表单与输出引用，成功步骤可复用；网页采集支持失败详情重试；文档索引增加命中位置和来源变化提示。
- 数据库迁移前一致性备份，兼容导入旧 JSON 记录；统一 Python 3.10 环境；Windows 更新不再先清空安装目录或卸载旧版本。
- 移除思维导图入口、实现和打包资源；已有导图用户文件保留。

## 验证与已知范围

发布前 Windows 本机通过 65 项 Python 测试、浏览器完整流程、生产构建及冻结程序桌面桥接验证；静态检查无错误，保留 91 条风格警告。规模回归覆盖千页 PDF、十万行 Excel 预览和千文件批次；LibreOffice、FFmpeg 与 RapidOCR 原生检查通过。

此版本按用户明确要求正式发布。GitHub Actions 会执行三平台检查与打包；三平台真实安装、升级、恢复、退出以及全部文件变体和真实登录网站的人工验收尚未完成，详见 [实施与验收记录](../refactor-implementation.md)。Word 不支持在跨页段落或跨页单个表格行内部无损截断，遇到此范围会明确报错。
