# V1.0.4 Phase 1 开发记录

## 阶段目标
- 按照《功能设计文档 V1.0.4》中的 Phase 1 规划，实现四套新增工具的 P0 级功能。
- 同步扩展 Python API 体系与前端 Vue 组件，确保桌面端可以直接调度图片、文本、视频、文件工具链。

## 本次交付内容
1. **后端能力**
   - 新增 `api/utils` 工具集，提供参数校验、单位换算、进度回调与统一返回格式。
   - 新增 `api/image.py / text.py / video.py / file.py`，落地图片格式转换/缩放/压缩、文本编码/JSON/大小写/哈希、视频转换/压缩/截取、文件搜索/目录分析/压缩解压等核心方法，并在 `api/api.py` 中对外暴露。
   - 扩展 `pyapp/requirements.txt` 引入 `py7zr` 以支持 7Z 压缩格式。
2. **前端界面**
   - 在首页卡片中新增「图片处理」「文本工具」「视频处理」「文件管理」四个入口，配套 Element Plus Drawer 面板（`ImageTool.vue`、`TextTool.vue`、`VideoTool.vue`、`FileTool.vue`）。
   - 新建共享组件（`FileSelector`、`ProgressBar`、`ResultTable`、`PreviewPanel`），统一文件选择、进度展示与结果回显体验。
3. **交互与可视化**
   - 图片工具涵盖格式转换、批量缩放与压缩结果列表；文本工具封装编码、JSON、大小写与哈希视图；视频工具提供格式转换、压缩、截取三大 Tab；文件工具实现搜索表格、目录统计卡片以及 ZIP/7Z 压缩解压操作台。

## 验证建议
1. 执行 `pnpm run start` 启动桌面端（需本地安装 FFmpeg 以启用视频相关能力）。
2. 在「核心能力」区依次打开四个新面板，按照 UI 提示选择示例文件：
   - 图片：准备若干 PNG/JPG，测试格式转换与压缩输出目录。
   - 文本：输入示例 JSON / Base64 字符串 / 不同命名文本，确认结果侧内容。
   - 视频：使用 MP4 测试格式转换及截取片段（依赖 FFmpeg）。
   - 文件：选定目录运行搜索和分析，准备示例文件/文件夹验证 ZIP/7Z 压缩、再用同一面板解压。
3. 留意控制台日志，如需调试 FFmpeg 路径，可在系统 PATH 中补充或在命令行验证 `ffmpeg -version`。

## 下一阶段（Phase 2）展望
- 图片：补全水印、裁剪、旋转/翻转等 P1 功能，丰富批量任务进度反馈。
- 文本：实现正则处理、CSV↔JSON、去重排序、时间戳转换等子模块。
- 视频：追加音频抽取、帧图导出，以及更直观的进度/耗时提示。
- 文件：扩展批量复制/删除/改名、去重算法与分类整理 UI。
- 平台：根据 Phase 2 需求补充单元测试 stub，并评估对 FFmpeg/TinyDB 的自动检测提示。
