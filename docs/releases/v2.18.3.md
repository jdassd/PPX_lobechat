# PPX v2.18.3 — 网页采集默认缓存与冻结探针修正

承接 v2.18.2 的 Windows 网页采集修复：浏览器状态检测、安装和启动共用默认 Playwright 缓存，采集失败后可重新检测内核。补充冻结探针在 Windows cp1252 控制台打印中文 JSON 的兼容处理，避免报告输出异常让已完成的浏览器启动检查被判失败。

此前的冷缓存测试曾显式设置 `PLAYWRIGHT_BROWSERS_PATH`，没有验证默认环境；该覆盖缺口仍应如实看待。v2.18.2 的本机完整回归包含 206 项 Python、26 项 GUI 合约、静态检查、生产构建、完整 E2E、冻结默认缓存探针，以及 Windows 隔离默认缓存冷下载并通过公开采集接口启动到工具条就绪。其产品 API/UI 与本版相同，这些记录只作为继承的产品回归证据，不是 v2.18.3 最终构建或发布证明。

v2.18.2 没有正式发布：Windows 探针在浏览器和工具条启动成功后，因 cp1252 控制台输出中文报告失败，CI 随后取消。本版已在 CP1252 环境复现并验证修复。v2.18.3 的 GUI 构建、完整 Windows 冻结包、空隔离默认缓存的实际下载和采集启动均通过，冻结程序正常退出；PDF/AES、CAJ、OCR、图片处理与桌面接口检查也通过。正式安装包由已推送标签对应的三平台 CI 构建，最终发布证据见 [验证记录](assets/v2.18.3/verification.json)。

浏览器自动验证使用测试专用无头模式覆盖；不能据此认定原生人工点选、安装/升级/恢复或 Windows 合成器闪烁已验收。原生安装升级恢复、其他 DPI/多屏、CEF、广泛 OCR 与 LibreOffice 验收保持 pending。
