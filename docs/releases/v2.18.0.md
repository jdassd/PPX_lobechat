# PPX v2.18.0 — CAJ 转 PDF

PDF 工具新增「CAJ 转 PDF」，可一次选择多个 `.caj` 文件，在本机转换并保留原文件。

- 默认保存到每个源文件所在目录，也可指定统一输出目录；同名 PDF 自动另存，不覆盖已有文件。
- 每个文件分别显示成功位置或失败原因，单个失败不影响其余文件；任务中心可仅重试失败项。
- 支持结果接力和工作流，转换出的 PDF 可继续合并、拆分、压缩或提取文本。

支持内嵌 PDF 的 CAJ，能够重建缺失的页面树并修复 PDF 索引；HN、C8、加密以及无法解析的 CAJ 格式暂不支持。没有额外安装 CAJViewer 或 mutool 的要求。转换不额外执行 OCR，不保证原文件中没有的文本可检索性或目录书签。

实现参考 [caj2pdf-qt](https://github.com/sainnhe/caj2pdf-qt) 使用的 [caj2pdf](https://github.com/caj2pdf/caj2pdf) 容器布局，具体来源和许可证见仓库 `THIRD_PARTY_NOTICES.md`。

验证包含按上游布局构造的多页 CAJ、缺失页树、页序、同名保护、加密与不支持格式、取消、批量部分成功、任务中心失败项重试，以及真实 API 的浏览器浅色/深色流程。当前没有真实论文 CAJ 样本集，不能据此宣称兼容所有 CAJ 文件。正式安装包来自已推送标签提交的三平台成功 CI；原生安装、升级、恢复等人工验收继续以 `docs/refactor-acceptance.json` 为准。
