# PPX v2.17.6 — 浏览器采集流程修复

修复浏览器采集首次安装、页面点选回调和匹配数量显示，并让 Google 验证后的采集错误与恢复状态更清楚。

## 内容

- 冻结应用通过内置 Playwright Node 驱动安装 Chromium，首次使用时能正确启动安装流程。
- 浏览器点选期间持续处理 Playwright 事件，前端显示实际匹配数量，预览和正式采集共用一致的选择状态。
- 启动、安装和采集失败时保留可理解的错误及重试入口；Google 验证页提示完成验证后重试，并保留浏览器会话。
- 点选 E2E 在页面跳转时等待工具条就绪，避免短暂导航状态中直接查询定位器。

## 验证范围

浏览器功能已在真实产品 API 的有头浏览器中使用用户提供的 Google 搜索网址完成工具条点选、两行预览和两行采集；冻结 Windows 程序从空隔离缓存实际下载并启动 Chromium 130.0.6723.31。相同实现的工具条点选导出 Excel、Google 挑战页恢复与 v2.17.5 Windows 冻结冒烟证据列于 [验证清单](assets/v2.17.6/verification.json)。这些继承证据不替代 v2.17.6 最终冻结构建和 Tag CI。

v2.17.6 真实点选专项连续三轮通过，生产构建和最终 Windows 冻结冒烟通过，包含包内浏览器命令、桥接、AES 切页、图像和实际 OCR。三平台完整验证和正式发布状态以已推送提交对应的 Tag CI 为准。原生界面首次下载、安装器安装升级恢复、其他 DPI/多屏、CEF、广泛 OCR 与 LibreOffice 仍保持 pending。
